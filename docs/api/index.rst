API Reference
=============

Reference for the importable Python API, generated from the NumPy-style
docstrings.

iceberg-ops is alpha software: until 1.0, any release may change these
APIs. The schema-migration modules are the core of the project. The
data migrator and the Apache Polaris policy executor are experimental,
and the maintenance helpers are basic and frozen in scope; their pages
say what each one does not cover.
